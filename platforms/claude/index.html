Claude Code

Claude Code 是 Anthropic 的编程工具。个人用户可通过 Claude Pro 或 Max 订阅登录使用；选择套餐时，应结合常用模型与五小时、每周窗口观察实际消耗。

适合什么人

Claude Code 适合希望在终端、IDE 或桌面中使用 Claude 完成代码修改、调试和项目理解的用户。个人 Pro 与 Max 订阅同时覆盖 Claude 应用和 Claude Code；两者的使用会影响同一组用量限制。

若需要把模型接入自己的服务或按实际 Token 付费，应分别比较 API 计费。个人订阅月费与 API 余额不能直接互换。

Claude 应用与 Claude Code 共享用量，受五小时和每周窗口限制。对话长度、所选模型、思考强度和任务复杂度都会改变实际消耗，不能按固定消息条数判断能完成多少工作。

表中的 Token 容量来自历史社区样本及模型、套餐倍率换算，包含外推假设，不是官方固定 Token 配额。月参考按周用量换算，不是额外发放的月额度；不同模型与窗口的数值不能相加。

登录与计费方式

在 Claude Code 中使用个人订阅时，登录订阅对应的 Claude 账号。若当前使用 Console 按量账户，可通过 /login 切换登录方式。

如果配置了 ANTHROPIC_API_KEY，客户端会优先使用 API Key，并产生相应 API 费用。准备使用订阅额度时，应先核对认证方式，避免把 API 支出误认为订阅内用量。额度耗尽后开启的额外付费用量也需单独预算。

本站将该平台标为需要境外网络与支付条件，购买前确认官方支持地区和账号资格。
