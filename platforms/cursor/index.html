适合什么人

Cursor 提供 AI 编程编辑器、本地与云端 Agent，以及 CLI 和 SDK。它适合希望在编辑器中完成理解代码、规划、修改与验证的开发者，也支持将部分任务交给云端执行。

如果主要使用 Grok，可以比较新的共享订阅。如果主要使用 Claude、GPT、Gemini 等第三方模型，先核算额外模型费用，再决定是否值得购买更高订阅档。希望把订阅直接作为其他编程工具的模型接口时，应另行确认兼容接入能力。

适合已确认需要更高共享额度的用户；与旧 Cursor Ultra 的第三方月度额度分开比较。

各模型共用套餐积分；每 5 小时和每周限制同时生效。部分周期金额按月价或季价换算，仅作比较；是否提供该周期订阅以平台实际提供为准。“不适用”表示没有可用价格，0 表示免费。

2026-10-12 发布的 X Subscription 将 Cursor、Grok、Grok Bot 与 X 权益组合在一起。新订阅的 Grok 使用量按周刷新并在相关产品间共享；不同产品会消耗同一池，不能将各产品权益相加当成独立额度。

Premium 及以上能使用第三方模型，但其调用费用从首个请求起另付，月费不包含这部分额度。 Plus 支持标准速度的 Grok 4.7、4.6、4.5 与 Composer 2.5；Grok 固定 medium effort，Grok 4.7 限 256K 上下文。Free 的精确模型与请求额度没有完整公开清单，不套用付费档支持范围。

旧 Pro、Pro+、Ultra 和印度 Start 已停止新购，符合条件的现有账户可保留原价格与权益。迁移为自愿选择，迁移后不可回退；不迁移时继续保留原套餐。存量年付的剩余有效期和迁移退款应在账户中确认。

印度 Start 的原月费以印度卢比文本保留；没有美元报价，不参与人民币预算换算。它限制地区、速度、effort 与功能，不是面向所有地区的低价 Pro。

这里汇总平台新旧个人方案的已确认模型，不表示每个套餐都支持全部型号，也不表示全部调用包含在月费中。具体套餐以支持关系及费用说明为准。

新订阅的 Grok 与 Composer 使用 Cursor 模型共享周池，Premium 及以上的第三方模型按实际输入、缓存与输出另付费。Grok API 单独计费，不扣减应用间共享周池。旧 Pro 系列则有 Cursor Models 与 Other Models 两个月度池；Composer 2.5 使用 Cursor Models 池，Gemini 4 Argon、Muse Wonder 等第三方模型使用 Other Models 池。

同一模型的高速和长上下文费用不同。Grok 4.7、GPT-5.6 系列及 Haiku 5.5 的输入长度阈值是计费条件；默认上下文和最大上下文另看说明。高速档属于同一模型的服务方式，不是新的模型身份。

Fable 5.1 在启用隐私模式时需要先同意其数据保留政策，部分请求可能自动回退到 Claude Opus。购买前应确认自己账户是否已开放该模型。

为什么没有固定 Token 额度

官方的新订阅公布了共享额度倍率，未公布可稳定换算的固定美元或 Token 基础池。不能仅凭月费、额度倍率或旧请求次数确定可用 Token 总量。旧两池的当前固定额度也需要按实际账户确认。

模型价格已公开的输入、缓存读取、缓存写入与输出费用均保留；有费率不代表知道总额度。代码、会话长度、缓存命中和输出量会改变实际消耗，模型支持名单也不能相加为月额度。

编辑器、CLI 与 SDK

编辑器适合交互式开发；CLI 可在终端中工作，官方还提供无界面与 CI 使用方式。SDK 用于驱动 Cursor Agent，它管理的是 Agent 会话及工具，不应直接理解为任何第三方 Harness 都能调用的兼容模型接口。

BYOK 使用的是自己在模型提供方的账户与费用，不能把自己的 Key 当成 Cursor 订阅额外赠送的额度。自动路由与子 Agent 可能选择其他模型，判断费用时应查看实际请求明细。

网络与支付条件

访问与支付条件：境内网络不可用，支持境内支付。支付方式的实际显示、账户和订阅资格以官方结算页为准。印度 Start 有独立地区与付款渠道要求。
