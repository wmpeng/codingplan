字节·方舟 Coding Plan

方舟 Coding Plan 是面向个人编程工具的多模型订阅。Lite 与 Pro 适合希望按月管理开支、在国产模型间切换的用户；它与方舟按量 API 和 Agent Plan 分别计费。

适合什么人

希望在同一个个人编程订阅中切换豆包、DeepSeek、GLM、Kimi 等模型，可以比较方舟 Coding Plan。选择时优先看自己的常用模型、任务消耗和工具兼容性，支持多模型不代表每个模型有独立额度。

本页介绍个人 Coding Plan。方舟通用按量 API 与 Agent Plan 是不同产品，密钥、端点、抵扣规则和活动不可直接互套。

接入工具时先查端点

在订阅控制台获取 Coding Plan 的 API Key，按官方支持列表配置编程工具。专用 Base URL 为 https://ark.cn-beijing.volces.com/api/coding/v3，不要填成普通方舟 API 的 /api/v3；模型 ID 按官方示例填写。

接入后用小任务确认模型、用量面板和扣减是否符合预期，再连续运行长任务。个人订阅的使用范围与限流规则以官方条款为准，需要通用服务端调用时另行比较按量 API。

Kimi K3.1 Pro 的限时抵扣

Lite 与 Pro 均支持 Kimi K3.1 Pro。2026 年 10 月 24 日至 11 月 9 日 23:59:59（UTC+8），其可用量与 Agent Plan 对应五折活动期间相当。Token 参考按官方系数与历史测量基准推算，不是固定官方 Token 配额；其他模型和套餐窗口仍按各自规则计算。

Kimi K3 的旧优惠公告截至 10 月 25 日，但当前活动状态仍列进行中，是否恢复常规系数待确认；不能把 K3.1 Pro 的新活动期限当成旧 K3 延期。

价格、活动与可用模型可能变化，购买和接入前请核对官方页面。本站的选择建议不代表服务承诺。
