适合什么人

希望使用 OpenAI 官方模型完成代码实现、排错和项目任务，可以比较 Codex 个人订阅。CLI、编辑器扩展与其他客户端的权限受套餐和开放进度影响；先确认自己需要的入口，再选档位。

订阅与 API Key 是两种付费方式：用 ChatGPT 账号登录消耗订阅用量；使用 API Key 按 API 规则收费，订阅月费不等于通用 API 余额。

Terra 已向 Plus / Pro 开放，CLI 需 0.159.0 或更高版本；支持 Fast，不包含 Ultrafast。Terra 的订阅可用量为同档 GPT-6.1 Sol 的 2 倍；表中按同套餐 Sol Standard 的参考量 ×2 估算，Fast 再乘 0.4。两倍关系有官方成员说明，绝对 Token 数仍继承 Sol 的估算误差，并非官方固定配额。

模型权限与速度权限需要分别看。GPT-6.1 Sol 可用于复杂代码任务，Terra 适合文字、图像理解和电脑操作，Luna 适合范围明确的日常任务；具体可选项由账号、客户端和开放进度决定。

速度与消耗倍率

Standard、Fast、Ultrafast 是同模型的速度档。Fast 消耗包含的订阅用量为 Standard 的 2.5 倍，另购 Credits 为 2 倍；Ultrafast 则分别为 8 倍、6 倍。消耗倍率不等于完成所有任务都能按同样倍数提速。

个人订阅中的 Ultrafast 目前限 Pro $500，支持 GPT-6 Astra 和 GPT-6.1 Sol，仍取决于客户端开放情况。使用 API Key 时遵循 API 计费，不能套用上述订阅或 Credits 倍率。

Plus 有五小时窗口，Pro 当前没有独立五小时限制，仍需观察周用量。Codex 与 ChatGPT Work 等共享额度功能会互相影响剩余量，以用量面板和重置时间为准。

表中的 Token 数是站内经验估算，不是官方固定配额。参考值按缓存命中率 95%、输出占总 Token 的 0.5% 换算；模型扣减系数来自经验估计，不能把它当作 API 美元价或可购买 Credits。

周、月参考以 Pro $100 同模型为基准：Plus 为 1/5，Pro $200 为 2 倍，Pro $500 为 5 倍；这是估算关系。Plus 五小时暂按本档周参考的 1/6.4，月参考按周 ×4 比较，不是额外一份月额度池。不同模型、速度档和窗口的数字不能相加；Free、Go 的精确 Token 量保持待确认。

长上下文、更多思考输出或较低缓存命中都会改变实际消耗。官方另购 Credits 价格也不能反推出包含的订阅额度，选择时应结合真实任务观察。

登录与查看余量

在官方客户端选择 ChatGPT 登录使用订阅；如选 API Key，先确认所用 API 账号、项目和付费方式。CLI 内可用 /model 查看模型、/status 查看当前用量，速度设置与模型选择分别检查。

若额度耗尽，先判断耗尽的是哪个共享窗口，再决定等待、升档或购买 Credits。购买前确认所在地支持、网络及支付条件；本站将该平台标为需要境外网络与支付条件。
