先看是否适合自己

智谱 GLM Coding Plan 把模型使用额度打包为订阅，主要用于代码生成、修改、调试和代码库问答。它适合已经习惯 GLM，或希望在现有编程工具中接入 GLM 的个人开发者。

  • 可以优先考虑：主要围绕 GLM 工作，希望按固定周期管理预算，并愿意根据实际消耗选择套餐档位。
  • 先比较再决定：经常在不同厂商模型之间切换，或希望为自建应用购买通用 API 服务。
  • 购买前先确认：工具是否在支持范围、使用哪个接入端点，以及自己的工作量会先触及哪个额度窗口。

本页介绍国内个人套餐；国际版与旧套餐的价格和权益可能不同。

积分不是固定数量的请求，也不是固定数量的 Token。同一次任务包含多少输入、缓存和输出，以及所用模型与时段，都会影响抵扣。长对话和多轮 Agent 工作也可能产生多次请求。

这两个窗口需要同时满足：短时间集中执行任务可能先碰到 5 小时上限，持续多天使用则可能先碰到周上限。额度刷新方式和余额请在官方用量页确认。

本站的价格与额度提供统一条件下的用量参考。它用于横向比较，不是平台承诺的固定 Token 包，不能据此保证一个项目一定能完成多少轮。

接入工具与使用边界

使用前先按官方接入指南确认工具与协议，再配置对应的编程端点和密钥。能在工具里填写 API Key，并不自动意味着请求会消耗这个订阅的额度。

建议按以下顺序检查：

  1. 确认正在使用个人套餐对应的账号和密钥。
  2. 按所用工具的官方指南配置服务商与端点。
  3. 先运行一个小任务，检查用量是否记入预期的套餐。
  4. 确认正常后，再放大到长任务和多项目工作。

如果是为自己开发的网站、应用或其他 API 服务选购模型，需要另行确认其适用计费方式；不要把编程订阅当成适用于所有调用场景的余额。

智谱选购时容易混淆的地方

国内版、国际版与旧套餐

本页对应智谱国内平台的个人套餐。国际版的价格与权益不同；旧套餐的文章、截图或账号权益也可能不同。比较时应同时看地区、产品线和记录时间，不能只比较 Lite、Pro、Max 这些档位名称。

官方工具的额外权益

某些权益与指定工具、模型或活动时间有关。若你主要为了某项加成购买，请打开当前套餐说明核对条件，并确认自己使用的客户端也适用。限时权益不应直接当作长期基础额度。

先分清为什么要升级

如果问题是模型不适合任务，提高套餐档位未必有帮助。如果问题是频繁达到额度上限，再结合实际消耗评估更高档位。订购长周期之前，也应阅读官方使用须知，确认续订与退款条件。
