DeepSeek 官方 API

DeepSeek 官方 API 按实际调用计费，适合希望直接使用 DeepSeek 模型、无需按月购买固定订阅的用户。预算取决于输入、缓存、输出和额外工具调用，充值金额不是固定 Token 配额。

适合什么人

主要使用 DeepSeek、调用量不固定，或需要按实际消耗支付费用时，可以考虑官方 API。与固定月费订阅比较时，应按自己的输入、缓存与输出组成估计成本，而不只看其中一项单价。

这是开放平台 API，与免费网页对话分别使用。它没有订阅月费对应的固定 Token 包，余额可支持多少工作取决于实际任务。

搜索与抓取另计费用

模型 Token 费用与 Search／Fetch 请求费用分开。独立 Search、Fetch API 各为每千次成功请求 5 元，不能按“模型支持工具调用”理解为这些服务全部免费。

在 DeepSeek Harness、Claude Code、Codex 中使用 DeepSeek API 时，Server 端 Search／Fetch 当前免费；官方公布从北京时间 2026-11-01 00:00 起按次收费。规划跨过该日期的自动任务时，应把工具费用纳入预算。

接入与预算管理

在开放平台创建 API Key 并充值，按官方文档选择协议：OpenAI 格式 Base URL 为 https://api.deepseek.com，Anthropic 格式为 https://api.deepseek.com/anthropic。具体工具的字段、模型名和思考设置应按对应官方接入指南填写。

先运行小任务查看账单中的输入、缓存和输出，再估计长期支出。控制台余额、并发及服务限流都可能影响连续调用，不能把“按量计费”理解为没有任何使用限制。密钥只保存在受信任的客户端或服务端。
