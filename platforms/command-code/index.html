先看是否适合自己

Command Code 是面向个人用户的多模型编程订阅。当前收录 Go、GOAT、Pro 三档，月费从 $1 起；使用时按模型实际 Token 价格扣减美元 Credits，适合希望在一个入口中切换多家模型的开发者。

  • 可以优先考虑：想用较低月费尝试多家模型，或需要在 Claude、GPT、Gemini、Kimi、GLM、DeepSeek、MiniMax、Qwen 等模型之间切换。
  • 先比较再决定：长期只使用一个模型，或更看重某一家官方平台的原生工具、服务稳定性和独立账户体系。
  • 购买前先确认：常用模型的独立月额度、所在地区是否可用，以及所选套餐能否在自己的客户端中使用。

本页沿用本站现有平台、套餐、模型和 PlanModel 记录。介绍更新时间与数据记录日期分开显示；用量表是统一工作负载下的计算参考，不是官方承诺的固定 Token 上限。

本站 Token 用量按输入占比、缓存命中率约 95%、输出占比约 0.5% 的统一工作负载计算，适合比较量级，不代表所有任务都能完成同样多的 Token。Ling 的每日请求上限、免费模型活动和模型地区限制无法用这套口径替代。

Command Code 同时有五小时、每周和每月窗口。GOAT、Pro 的模型月额度与短窗口按现有套餐规则缩放；部分模型还存在有截止日期未公布的限时额度，购买前应查看官方当前总表和账户页面。

客户端与接入边界

Go 当前只能在 Command Code 客户端内使用，且现有平台资料记录其稳定性较弱。使用 Go 之前先完成一个小任务，确认登录状态、模型选择和 Credits 扣减都正常；不要因为客户端显示了模型名称，就默认所有套餐都能在任意兼容工具中调用。

对 GOAT 和 Pro，也应按官方套餐说明确认当前客户端、模型 ID、地区和接入方式。遇到调用失败时，先区分模型不可用、客户端限制、额度耗尽和上游服务波动，再判断是否需要换套餐。

购买前容易混淆的地方

套餐价格、Credits 与 Token 不是同一个量

月费是订阅价格，Credits 是按模型扣减的使用额度，表中的 Token 是特定工作负载下的换算参考。不能用 $1/月、$10 Credits 或某个模型的请求示例，直接推导所有模型的固定调用次数。

免费和限时额度不能当作长期权益

当前资料中有免费模型、每日请求上限和限时月额度。它们都可能随官方价格表调整；长期预算应以常规额度和自己实际使用的模型为准，并记录核对日期。

不同模型档位不要合并比较

同一模型可能有峰谷、上下文或服务档位。比较时先确认自己使用的具体模型 ID 和档位，再看对应的 Credits 扣减与额度；不要只看模型名称或平台支持数量。
